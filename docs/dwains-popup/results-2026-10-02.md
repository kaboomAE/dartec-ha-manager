# Dwains Dashboard Next 1.8.0, 1.8.1 and 1.10.0, with and without the dashboard fix (2026-10-02)

Produced by `tests/live/run_live_dwains.py` on Home Assistant 2026.9.3, in
Firefox and Chromium. Demo data in the containers; on the bench, a state-only
thermostat added for the run and removed after it.

- **Columns.** "Dashboard fix" is one of:
  - `served`: what the Home Assistant under test serves. In a container that
    is this tree's gated fix. On the bench it is the released agent 0.24.0's
    copy.
  - `tree`: this tree's fix, substituted at the network. Bench only.
  - `file`: agent 0.24.0's copy, substituted at the network.
  - `blocked`: no fix.
- **Mounted** counts each time Dwains' picker was connected to the page,
  over two openings. A move by the fix adds one each time.
- **setConfig per change** counts the editor's `setConfig` calls for three
  changes: choose an entity, set an option, clear it.
- **The 16 "other errors"** in each run are identical with every fix mode:
  `card thermostat Error: Specify an entity…` from a picker preview without
  an entity. The fix adds no error of its own.

What the table shows:

- **Upstream fixed all three bugs in 1.8.1**, and they stay fixed in 1.10.0.
  With the fix blocked, Dwains is clean on its own.
- **The released 0.24.0 fix never moves the picker twice.** It only moves one
  that Dwains put on `document.body`.
- **0.24.0 does hand the editor's config back a second time on every change.**
  In these runs that was harmless: the entity was kept, clearing an option
  worked, and no error appeared. But it also handed back a stale config for a
  change without a card type, which Dwains 1.8.1 deliberately ignores
  (`tests/test_dashboard_fix.py`). This tree's fix gates it to pre-1.8.1
  pickers.
- **On 1.8.0, an option cannot be cleared again with any fix.** That was
  upstream's #12, fixed in 1.8.1.
- **The notification row still needs the fix on 1.10.0.** It measures 1.25:1
  without the fix and 12.59:1 with it, in every run. Dwains still hardcodes
  `rgba(255, 255, 255, 0.78)`.
